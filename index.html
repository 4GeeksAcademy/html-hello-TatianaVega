¿Qué es una skill en AgentHub?

Una skill es una capacidad que se puede adjuntar a un agente de IA, como navegar por la web, leer documentos o gestionar calendarios. Cada agente se configura con las skills que necesita para su tarea, y el cliente paga por las skills contratadas.
